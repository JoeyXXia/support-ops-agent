## 复现

从仓库根目录按 README 安装现有浏览器依赖。启动专用 Compose 环境，确保端口可用。自定义端口时让 SUPPORTOPS_DEMO_PORT 和 SUPPORTOPS_E2E_URL 对应。运行以下命令。

```powershell
docker compose -p supportops-day28 up --build --wait --wait-timeout 120
node apps/web/record-demo.mjs
python -m scripts.validate_day28_cases
python scripts/check_offline.py
npm --prefix apps/web run format:check
npm --prefix apps/web test
docker compose -p supportops-day28 down
```

最可能失败处是 Docker 引擎未启动、端口占用、Chromium 未安装、业务状态断言变更，以及误把合成开发样例当作冻结测试集。录制器限定回环入口，视频保存在忽略目录，发布件为已实际验收的副本。复现时专用项目卷可保留用于诊断。
