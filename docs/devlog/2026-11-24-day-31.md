# Day31 · 答案质量与待人类校准

北京时间 2026-11-24。本地 main 和 GitHub 起点为 `98d1538`，工作区干净。Day30 已覆盖工具和真实写入结果，Day31 单独检查回答、依据、引用和弃答。

1. `scripts/capture_day31.py` 从冻结开发集读取 QA 子集，在专用本地 PostgreSQL 上调用现有 GraphAgent 和 knowledge-mock-v1，采集实际 BM25 上下文、答案和引用，同时保留一条旧问法正对照。
2. `evals/day31` 保存四维规程、20 条初标及理由、人工复核表和 5 个分歧分析。`scripts/audit_day31.py` 核对冻结哈希、逐例覆盖、初标来源，计算结构比较。
3. `reports/day-31-*.json` 保存实际观察、比较结果和验证记录。测试分区未用于评分。本轮未运行 LLM judge 或 live 模型。

## 可观察验收

- 20 条冻结开发 QA 均完成，逐例可检查真实检索上下文和最终答案。旧问法正对照返回引用，单列。
- 四维评分具备 0、1、2 和不适用规则。20 条助手初标均有逐例理由。真实人类已确认 0 条，该验收保持待办。
- 保存结构规则版本、逐例分歧和 5 条具体分析。结构通过不能替代质量结论。
- 通过冻结哈希、复核材料与观察一一对应的校验。区分缺上下文、已检到依据仍弃答，以及适当弃答。

## 实测与复现

2 条追问版本，18 条弃答。16 条可答题的标注来源全部进入最终检索上下文，但 mock 没有引用或作答；2 条商业问题安全弃答。旧问法对照引用 `quotas#limits` 成功。结构规则通过 20 条，助手初标充分可接受 2 条，分歧 18 条。它们是本次确定性 mock 和初标观察。

119 项离线测试通过（59.201 秒）。采集、哈希与逐例审计通过；重新比较与保存的 JSON 一致。两次伪造人类来源的负对照均被审计拒绝。

从仓库根，对回环临时 PostgreSQL 的 `_test` 库设置 `DATABASE_URL`，依次执行 `python -m alembic upgrade head`、`python -m scripts.seed_demo` 与 `python -m scripts.capture_day31 <新输出文件>`。捕获用 CLI 程序会拒绝非回环或非测试库配置。只复核已保存结果可运行 `python -m scripts.audit_day31`。临时数据库已清理。

主要边界是精确问法 mock 对转述缺少覆盖、候选来源可用与最终引用完成不同，以及初标无法替代人工复核。Day31 待真人复核 20 条后才满足当日全部验收。
