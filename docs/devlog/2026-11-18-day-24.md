## 五项验收与实测

- 历史默认最近 20 条，仅当前账号；limit 允许 1–50。列表不包含答案、事件和引用正文。新 HTTP 记录有真实创建时间；旧记录及未记录时间的操作员 CLI 记录显示“创建时间未记录”。内存模式明确提示重启丢失；持久模式从数据库读取。
- 不查看后台日志，浏览器可以从新建生成草稿、查看租户/工作区/动作/参数/期限，批准后查看工单 ID 并跳转实际工单详情；拒绝后显示已拒绝，结果 ticket 为空。
- Playwright 暂停审批 HTTP 响应，实际观察批准与拒绝两个按钮都禁用；放行请求后正常完成。按钮防重复只改善交互，数据库审批/key/事务回执仍是副作用保护，不把前端禁用视为幂等保证。
- 待审批详情、历史列表和引用原文的 URL 经真实浏览器刷新仍可读取；引用侧栏展示产品版本、修订、来源行号与保存的原文。历史与详情通过既有会话访问，未把数据或令牌放到 localStorage。
- 有效 UUID 但不属于本次运行的引用返回 404；其他主体的运行/引用也为 404。非法 hash 路径不形成 API 资源路由。测试在禁止 Path.read_text 的条件下读取正常/错误/越权引用，未发生文件读取；浏览器无效引用清空旧原文，未请求 data/demo 或 .env 路径。

## API 与 URL

| 入口 | 行为与边界 |
| --- | --- |
| GET /runs?limit=20 | 会话主体本人摘要；默认20、上限50；memory/postgresql 标记，不返回完整答案 |
| GET /runs/{id} | 继续使用原有本人归属检查，供刷新与显式重新读取 |
| GET /runs/{id}/citations/{chunk_id} | 两个 ID 都要求 UUID；先加载本人 run，再匹配已保存 citations，不接受文件路径 |
| #history | 历史页，显式刷新，不新增后台轮询 |
| #run/{id} | 当前运行详情；活动运行复用已有 SSE |
| #run/{id}/citation/{chunk_id} | 详情与引用侧栏；原文通过授权 API 查询 |
| #ticket/{id} | 复用 GET /tickets/{id}，查看工单当前状态；原 run.ticket 仍是执行回执快照 |

## 复现与失败修正

按 README 配置种子账号口令；启用 SUPPORTOPS_PERSIST_RUNS=1 并使用既有 PostgreSQL 迁移，才具备跨服务重启的持久历史。内存模式刷新可以读取尚在同一服务中的历史，但重启无法保留。新时间来自 datetime.now(UTC)，保存在原 JSON record 中，无需迁移旧数据。持久历史按已记录创建时间排序，无时间的旧记录最后按 ID 稳定排列，不将 UUIDv4 排序冒充真实创建顺序。

运行 `python scripts/check_offline.py`；配置显式专用 TEST_DATABASE_URL 后执行 `python -m unittest discover -s tests/integration -v`。前端命令为 `npm --prefix apps/web test`、`run format:check`、`run build`。持久历史测试重新创建了服务生命周期与 store，验证不是依赖内存缓存；本日浏览器验证的是页面刷新，没有把它写成新一次真实进程故障恢复演示。

浏览器夹具导入现有公共 Markdown，生成 mock embedding，强制持久模式并用合成测试口令。API 8024、Vite 5176 仅监听127.0.0.1。审批按钮等待通过暂停/继续 HTTP 请求验证；引用和工单来自真实本机数据库。Windows venv 启动器可能产生子 Python 进程，清理时核对 server.py 的完整命令行并用停止标记让父进程清理 schema，不能只相信旧 PID。

初次离线测试把另一个主体固定种子数据的初始化也纳入文件禁读断言，出现失败；先完成该固定初始化后，仍严格禁止引用查询期间的路径读取，95 项通过。新数据库测试和浏览器夹具最初漏传 import_batch 必需的 tenant_id=None，修正为显式公共范围后43项通过。浏览器子进程的模块路径与一次 CLI 引号问题也已修正；未改业务授权来迁就测试。PID 复用检查阻止误停无关进程，没有覆盖现有用户改动。

## 最可能失败的边界与本日限制

旧审批可能已过期或被决定，服务端依旧校验摘要、期限与主体；失败后通过“重新查询当前运行”实际读取最新记录，不再对暂停状态无效地重启 SSE。新申请使用“新建排查”，不修改旧批准内容。

URL 只携带不透明 ID，不能替代服务器授权。账号/路由切换会卸载旧视图并关闭旧 SSE；已被服务器接受的写入不会因导航或退出而撤销。数据库唯一约束和回执继续保证同一审批动作的幂等，新 run 新审批是新逻辑动作。

历史只提供有界列表，无分页、搜索、批量删除、全量导出或新索引；旧时间缺失不能重建。未测大规模 JSON 排序性能。引用显示保存的原文与修订，来源路径是纯文本，不是文件下载链接；无效引用不回退为任意文件读取。浏览器验证为桌面视口，不声明移动端或生产部署验收。没有推进 Day25 MCP、Day38 SSE断线恢复或 Day48公开访客会话。
