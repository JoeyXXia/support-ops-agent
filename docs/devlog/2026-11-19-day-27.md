## 11 月 20 日 CI 追踪

GitHub 首轮 browser 和 offline 任务通过，database 任务失败。使用 Day27 构建的 Linux API 镜像和相同版本的 pgvector，在专用临时数据库运行 `python -m unittest discover -s tests/integration -v`，45 项中复现 1 项失败。失败用例为 `test_mcp_mode_retains_local_approval_write_and_knowledge`。[首轮 GitHub Actions](https://github.com/JoeyXXia/support-ops-agent/actions/runs/44538874337)

知识工具从 `DATABASE_URL` 取连接，原测试只把隔离引擎传给运行仓库。本机配置曾掩盖这个漏项。测试现在在作用域内显式设置 `DATABASE_URL`，并使用与运行仓库相同的隔离 schema。业务实现和断言保持原样。Linux 全量复测 45 项通过（44.875 秒），临时卷已清理。真实模型冒烟仍待凭据授权。
