## 五项可观察验收

- 正常订阅先取得快照、运行开始，再取得步骤和工具开始/完成事件；答案后为 run.finished。两次 mock 运行的事件类型顺序一致，连接内 seq 从 1 严格递增。
- 真实浏览器通过 Vite 代理，在注入延迟的工具尚未完成时显示“运行中”和“正在调用工具 get_workspace_usage”；当时完成标题数量为 0，最终正常完成，提交按钮恢复。
- 待审批阶段发送 approval.required 后结束本次流，不冒充 run.finished；批准后显式创建新订阅，真实 PostgreSQL 执行后得到完成状态和工单 ID。此项由真实数据库 ASGI 集成与 reducer 验证，未声明持久审批浏览器全流程验收。
- 模型异常发送失败终态，浏览器停止加载；SSE 请求被中止时显示连接错误并停止加载，观察 3.5 秒内仅一次 SSE 请求。点击“重新查询当前运行”才发起第二次请求，取得已完成结果。不是自动断线续传。
- 匿名为 401，其他主体和不存在的运行为 404。会话在每次轮询及每帧发送前检查，撤销后不继续发送已准备好的下一帧。订阅关闭不会取消后台运行；结束后连接槽位归还。

## SSE 协议

GET /runs/{id}/events 要求原有会话 Cookie 和 run 归属。响应为 text/event-stream，禁止缓存并设置 X-Accel-Buffering:no。每帧包括 id、event、单行 JSON data；JSON 信封为 seq、type、run_id、data，换行由 JSON 编码转义。

| 事件 | 含义 |
| --- | --- |
| run.snapshot | 当前可公开运行快照。新连接从当前快照和已知历史开始，非增量游标恢复 |
| run.started | 该次订阅观察到执行已开始；已结束记录标记 historical，不伪造原始开始时间 |
| step.started / tool.started | 逻辑步骤或通过预算的工具尝试开始；不展示模型内部思维链 |
| model.finished / tool.finished | 已有完成记录的公开投影；工具仅附 ok 标记，动作与引用在授权快照中提供 |
| model.error / tool.error / write.error / retry.scheduled / run.stopped | 已有脱敏失败、退避与预算停止记录 |
| answer.delta | 已生成答案的分发，complete=true；当前为一块完整答案，不是模型 token 流，也没有人为延迟模拟生成 |
| approval.required | 当前阶段进入待审批，附授权快照并关闭本次订阅 |
| run.finished | completed、failed、stopped 或 interrupted 的阶段结束快照 |
| stream.error | 实时传输/读取/授权异常，关闭订阅；不能据此认定后台任务失败或被取消 |

快照与事件都使用公开字段白名单；不推送原始 SDK 输出、内部请求、推理字段或异常文本。引用、动作参数与工单仍受原有主体归属检查。

## 失败边界与取舍

服务端每 100 毫秒读取当前运行，10 秒发送一次注释心跳，读取循环设 180 秒截止，前端另保留三分钟等待保护；每个主体同时最多 4 条 SSE 连接，超限 429。复用现有存储降低今日范围，但持久模式会有重复数据库读取；未测规模性能，不声称这是生产消息分发方案。

读取循环的截止不是网络发送阻塞时的严格墙钟保证；客户端等待保护用于避免静默连接一直加载，未测慢消费者与后台标签页计时精度。

连接内事件序号不跨连接持久化，不保证跨节点重放或跨进程恢复时的 exactly-once 事件投递。携带 Last-Event-ID 返回 409，浏览器在终态、待审批或错误时主动 close，禁止默认自动重连。Day 38 再处理断线恢复。

快任务可能在订阅建立前结束；仍返回授权快照、已知历史和终态，不能把回放称为实时逐帧观测。会话失效后已在网络缓冲中的字节无法撤回，服务端保证不再发送未授权的新帧。断开订阅仅清理连接，不取消已接受的任务；进程崩溃后的持久恢复仍需显式操作。

初次 lint 发现新增长行，格式化后门禁通过；逐帧撤销检查和工具开始时机在复核中收紧，相关测试验证最终行为。现场浏览器的延迟和故障是注入夹具，真实数据库审批与内存浏览器场景分别记录。CI 配置已接入 reducer 测试；本报告只声明本机实测，不预先声明 GitHub 托管 CI 结果。
