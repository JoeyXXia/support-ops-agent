# Day33 · 有界上下文与显式偏好

北京时间 2026-11-25。开始时本地和 GitHub main 为 `3463502`，工作区干净。Day32 已验证工具和身份边界。现有知识运行只接收一次性版本，运行历史不能承担当期事实状态。

## 三组可独立审核改动

1. `packages/agent/conversation.py`、`apps/api/memory.py` 和现有 runs/main。新增按完整身份归属的短期会话，分开最新原始输入、摘要和结构化事实。创建知识运行时读取该版本并交给原有上下文入口。
2. `packages/storage/preferences.py`、schema 与 `0007_user_preferences`。沿用已配置的 PostgreSQL，只保存用户明确确认的版本偏好，可删除，互不影响租户或用户。
3. `tests/test_conversation_memory.py`、`tests/integration/test_conversation_preferences.py`、使用说明、范围、日志和验证 JSON。没有新增依赖、服务或 UI。

## 五项可观察验收

- 15 条真实 ASGI 提交的 mock 运行均能完成，短期表只保留第 12 至第 15 条输入和各自 run_id。摘要始终在 96 字节内。
- 从 1.0 更正为 2.0 后，新运行的实际文档引用为 2.0，先前受理的运行仍引用 1.0。撤回后下个 mock 回答追问版本、工具调用为 0。
- 会话所有权来自服务端。其他租户和同租户其他主体的会话详情不可读，无权更新或应用。未登录会被拒绝，会话返回不可缓存。
- 长期偏好仅在真布尔确认后写入，显式选择才带入会话。重建服务生命周期后短期会话消失，长期偏好可读。删除会清除仍继承的会话值并保留同主体后续手动设置，另一租户不受影响。
- 容量和到期边界可重复验证。不同租户即使同用户名也不可访问原会话。

## 实测与复现

123 项离线测试通过（59.491 秒），51 项真实 PostgreSQL 集成测试通过（64.299 秒）。短期专项 2 项、持久偏好专项 1 项通过。首轮数据库回归有 1 项失败，迁移表集合的固定断言还未包含 user_preferences。补齐集合后重跑，迁移升级、降级检查全部通过。

首轮 15 轮用例在提交后立刻读取，遇到运行尚未转换终态。改为轮询有界等待终态后再断言，应用运行保持正常异步。开发中的 PEP 风格长行已由现有格式工具修正。

```powershell
python -m unittest discover -s tests -p test_conversation_memory.py -v
# 配置专用 PostgreSQL _test 库的 TEST_DATABASE_URL
python -m unittest discover -s tests/integration -p test_conversation_preferences.py -v
python -m unittest discover -s tests/integration -v
python scripts/check_offline.py
```

风险是把已经受理的运行当作可撤销，让历史原文覆盖更正，或者把偏好和授权绑定混在一起。当前版本事实只用于检索，不赋予新权限；原始旧文本只供会话查看。真实 PostgreSQL 与本地 ASGI 已验，模型用确定性 mock，无真实 API 请求。临时库和容器清理。摘要字节数与模型真实 token 消耗不同。
