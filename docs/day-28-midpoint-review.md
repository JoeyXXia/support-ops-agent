## 接下来最有价值的三项工作

| 优先项 | 原因与完成证据 |
| --- | --- |
| 冻结按场景分组的评测集 | 先防止相近问题横跨开发集和测试集。可审查地记录去重、分组和冻结后分布。 |
| 扩大行为回归并归类失败 | 验证引用、拒答、授权和审批结果，保存可复现失败样例与原因。不能用浏览器三个合成场景代表模型表现。 |
| 完善本地运行诊断和恢复验证 | 记录连接、会话、审批和模型失败各走哪条可观察路径。真实模型连通性在有效凭据可用后另验。 |

## 剩余风险与可裁剪内容

- 真实模型质量和真实向量检索效果缺少独立证据。将来接入后先做有界冒烟和离线评测。
- 登录会话仍为本机单进程；跨进程身份与生产部署需要独立设计。
- SSE 缺少持久游标，断线后需要显式重新查询。避免将发布版描述为支持无缝续传。
- 可延期第三方 MCP 服务与远程 OAuth、可视化报表、历史筛选和额外部署环境。保留三条验收主链与授权边界。

前 30 秒介绍合成 SaaS 场景。接着用约两分钟展示三条闭环，再讲清可信 HTTP 会话、保存引用、审批摘要及事务回执。最后展示一条真实边界证据，并说明已验证的本地能力和后续评测缺口。
